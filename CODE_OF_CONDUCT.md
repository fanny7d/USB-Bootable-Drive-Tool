# Code of Conduct

We are committed to a respectful, inclusive, and technically constructive community.

## Expected behavior

- Be respectful and assume good intent.
- Discuss ideas and evidence, not personal characteristics.
- Give actionable feedback and accept corrections gracefully.
- Protect user privacy and treat destructive disk operations with exceptional care.
- Respect project scope, licensing, and responsible disclosure requirements.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate privacy violations, destructive testing on other people's systems, and publishing unresolved security vulnerabilities are not tolerated.

## Enforcement

Maintainers may edit or remove content and restrict participation when necessary. For sensitive conduct or security concerns, contact the repository owner privately through GitHub rather than opening a public issue.
